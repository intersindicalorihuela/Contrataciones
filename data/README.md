# Contrataciones · datos mensuales

Coloca aquí el Excel maestro de contrataciones como `Contrataciones.xlsx`.

Cada vez que se sube una versión nueva de este archivo, el workflow
`.github/workflows/actualizar-contrataciones.yml` ejecuta `convert.py`
y publica el `index.html` actualizado en GitHub Pages sin pasos manuales.

Flujo completo en el [README](../README.md) de la raíz.
